# Culture: real CT characters (cameos) (DRAFT for owner review)

Part of `docs/game/culture.md`. Archetypes: `docs/game/culture-cast.md`. World content: `docs/game/culture-world.md`. Nothing here is in the game yet.

## Rules for this file

- **Only things they really said.** Every line is a real public post (or statement) by that person. No invented lines, no parody.
- **The in-game test (owner, 2026-10-09).** A line stays only if it makes sense when a resident of the town says it to the player. Out: anything that points at a tweet, a thread, a post, an article, an image or a link; anything that mentions Twitter or CT as the place we are in; replies to someone; lines that need the news of that day.
- **No dated lines (owner, 2026-10-09).** Out: an age or "years of", a price that dates the post, a countdown ("in the next 2 years"), a news item of its day (an election, tariffs, a bank failure, an ETF, a merge, a launch). A line must still read right in five years. Only a few seasonal lines stay, each marked with its day (Christmas, May).
- **Short bubbles (owner, 2026-10-09).** One bubble is at most about 140 characters (two lines). A long post is cut to its best one or two sentences. **(cut)** = sentences removed, the words left are unchanged. **(adapted)** = a few words changed so it can be spoken. Cutting and adapting use only the post's own content.
- **(?)** = the wording or the source needs a check against the original before shipping. Nothing marked (?) ships until checked.
- **Dialogue plays only on click.** Nothing is said because a player walked close. A click shows **one random line** of that character, never the same one twice in a row. Rare cameos appear only a few minutes per hour.
- **Source:** X posts read through search snippets and the public profile view; only the first posts of each profile were visible. Dates are as shown, or inferred from the post id (a month can be off). Re-copy each line from the original before shipping; a person who asks to be removed is removed the same day.
- **Market calls** on a card carry "old post, not advice". No line promotes a token. Lines that attack a named individual were left out.

**Left out:** Ansem (owner's call), Murad (the only verbatim text found was a token promotion), Do Kwon, Zhu Su and 3AC (plaque in the Rekt Garden only), anyone who died.
