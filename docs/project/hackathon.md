# Chogathon

Source: https://chogathon.chog.xyz/ (read 2026-10-06; re-check dates before submitting).

- **Theme:** build experiences powered by Chog NFTs. Test: *"take the NFT out, does it still work?"* If yes, rethink. NFT essentiality is a pass/fail gate.
- **Format:** 14 days to build, 7 days judging. Solo or team up to 5. Any category; vibe coding allowed. Start: the site countdown read ~20h35m on 2026-10-07 (≈ 2026-10-08 evening, timezone unconfirmed), so building ends ≈ 2026-10-22; confirm exact times in Discord. The art prototype predates the start and must be declared as pre-existing work.
- **Prizes:** $15,000 minimum (may drop to $10,000 if submissions are weak). 50 winners: 1st $4,500, 2nd $2,500, 3rd $1,500, descending, 31st–50th $50 each.

## Judging (weights)

| Criterion | Weight |
|---|---|
| Novelty | 30% |
| Fun | 20% |
| Retention | 20% |
| Clarity | 15% |
| Execution | 15% |
| Bonus | optional `$CHOG` token integration |

Judges test alone within a week: the demo must be understandable and fun without other players.

## Deliverables

Project name and team; description and novelty; why the Chog NFT is essential; working demo or ≤3 min video with test instructions; repo, stack, attribution of pre-existing work; user feedback and roadmap.

## Registration

`/apply` on the site (sign in with X, Discord, Google or GitHub; ~2 minutes). Community: https://discord.gg/chog, main site chogathon.com.
